# ORION - Please read all of this before running the code.

A Python assistant that controls my Mac throug terminal commands and Ai screen control. Btw it asks for you to change some privacy settings in you Mac to allow it.(use demo video or reach out to me so i can show you around).

## Requirements

- macOS
- python
- OpenAI API key (i am doubting how to get this to revie as i cant share my key with you.)

## Run

I ask you to be fully aware of the fact this a v1 and it might not work as expected. AI tasks can be slow or click incorrectly. Website layouts, and login screen can interrupt tasks.

```
python -m pip install -r requirements.txt
export OPENAI_API_KEY="your-key"
python main.py
```

## Examples

- `open Safari`
- `type Hello from ORION`
- `capture`
- `do Open YouTube in Safari`
- `setup` —  GitHub repository and VS Code setup routine
- `exit`

MOVE THE POINTER TO THE TOP-LEFT corner to stop automattion.
